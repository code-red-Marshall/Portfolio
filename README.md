# Bhargav Nath — Product Portfolio

A personal portfolio highlighting work across AI product management, technical product management and enterprise SaaS.

## Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Portfolio structure

- Homepage: positioning, selected work, experience, capabilities and contact.
- Case studies: dedicated project narratives covering the problem, product decisions, execution, technical approach and outcomes.
- Resume: served from the public directory.

## Deployment

The project is configured for static hosting. Netlify deployments should include the SPA fallback in `public/_redirects` so direct case-study links resolve to the application entry point.

## Content integrity

Only publish metrics that have been verified and can be explained with a baseline, measurement period and attribution. Keep employer-confidential information, customer data, credentials and internal security details out of public case studies.
